Bei jedem Aufruf einer Seite übermittelt der Browser technisch notwendige Daten an die Server von GitHub. GitHub ist nach dem EU-US Data Privacy Framework zertifiziert; für zertifizierte Unternehmen hat die EU-Kommission ein angemessenes Datenschutzniveau festgestellt (Angemessenheitsbeschluss vom 10. Juli 2023, Art. 45 DSGVO). Soweit dieser Beschluss nicht greift, stützt sich die Übermittlung auf Standardvertragsklauseln der EU-Kommission (Art. 46 Abs. 2 lit. c DSGVO).

Speicherdauer: Wie lange GitHub die Protokolle aufbewahrt, legt GitHub fest. Einzelheiten stehen in der Datenschutzerklärung von GitHub: docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

4. Keine Cookies, kein Tracking

Diese Website speichert keine Informationen auf dem Endgerät und liest dort keine aus (§ 25 TDDDG). Sie setzt keine Cookies und nutzt weder Local Storage noch Session Storage. Es gibt kein Tracking, keine Reichweitenmessung und keine Werbung.

5. Keine Inhalte von Dritten

Die Website bindet keine Inhalte anderer Anbieter ein: keine Karten, keine Videos, keine Schaltflächen sozialer Netzwerke und keine externen Skripte. Die Schriften Saira und Inter liegen auf dieser Website selbst; beim Aufruf wird keine Verbindung zu Google oder anderen Schriftanbietern aufgebaut.

In dieser Datenschutzerklärung stehen Links zu anderen Websites. Daten werden an diese erst übertragen, wenn ein Link angeklickt wird; dann gilt die Datenschutzerklärung der jeweiligen Website.
